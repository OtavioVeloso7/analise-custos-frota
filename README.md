# Análise de Custos de Frota 🚗📊

Projeto de portfólio para praticar análise de dados aplicada à gestão de manutenção de uma frota de veículos. A base utilizada é **fictícia e simulada**, sem dados de empresas reais.

## 🎯 Objetivo
Explorar os custos de manutenção e identificar padrões que possam apoiar decisões operacionais.

## 🧰 Ferramentas
- Excel — organização e exploração dos dados
- SQL — consultas e análise
- Power BI — dashboard e visualização (etapa futura)

## 📁 Estrutura prevista
- `data/` — base de dados fictícia
- `sql/` — consultas SQL
- `dashboard/` — arquivo e imagens do relatório Power BI
- `README.md` — documentação do projeto

## 📊 Perguntas de análise
- Qual é o custo total de manutenção?
- Quais categorias de manutenção geram mais gastos?
- Quais veículos apresentam maior custo?
- Como os custos variam ao longo do tempo?
- Qual é a distribuição por cidade e tipo de veículo?

Projeto em desenvolvimento. As análises e o dashboard serão adicionados conforme o avanço dos estudos.
